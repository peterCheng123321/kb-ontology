# 本田 CR-V + 雅阁 2018 探索性试验：结果

- 日期：2026-11-24（Asia/Shanghai）
- 范围：公开数据试验。投诉不存叙述原文，不输出、不入库车辆识别号。私有工单数据未公开。
- 数据窗口：NHTSA 投诉为接收日 2020–2026 分包中的本田 CR-V / ACCORD 2018；召回与调查为官方全量中覆盖该年款车型的记录；CodesList 码表；MechanicDB 免费样本；`vehicle_qa` 中「本田CR-V」「雅阁」问诊（只留品牌/车型/部件主类/去标识短结论）。

## 结论（先看）

**有一部分关系确实能串起来，但硬关系很少，能展示的主路径大多是候选。**

确实存在：

- 投诉按 `ODINO` 归并，并挂上年款车型与部件主类（硬结构）。
- 召回按 `CAMPNO` 归并，覆盖本切片 8 个活动。
- DTC 码表定义，以及样本里「故障码 → 维修步骤 → 零件」的硬键（切片里实际出现且落在样本中的码，如 `P0300`、`P0172`，可以走到步骤和零件）。
- 投诉与召回、投诉与调查之间，用「同一年款车型 + 部件主类」可以生成大量候选边。
- 中文问诊可用部件词表打到英文主类，再统计该主类在本切片的投诉数。

明确断开或很弱：

- **本切片 3 个调查的 `CAMPNO` 全部为空**，调查 → 召回这条官方硬键是 **0 条**。`PE22003` / `EA24002`（误触发自动紧急制动）和 `PE22011`（后差速器卡滞）都没有接到任何召回号。召回部件主类与调查部件主类在本切片 **没有交集**。
- 投诉没有官方召回号。MMY+部件主类候选量很大，但抽检说明 **过宽**：10 条里只有 2 条看起来对，2 条应否定，6 条单靠字段无法判断。
- 中文问诊几乎没有故障码（301 条里 2 条），不能靠 DTC 硬连。问诊没有年款，不能接到某一个 2018 投诉，只能接到部件池。词表里的「空调」在本切片投诉主类中不存在，计数为 0。
- 切片投诉叙述中抽出的故障码，只有一部分在 MechanicDB 样本里；不在样本里的码只有码表定义，没有步骤。
- 燃油系统投诉接到燃油泵召回，与叙述里抽出的失火码（`P0300` 等）在图上能同时出现，**不等于**该投诉已被证实是油泵缺陷。

## 五条演示查询与结果链

查询文本在 `queries/*.rq`，完整结果在 `queries/sparql_results.json`。下面只写链，不含车辆识别号或投诉原文。

**Q1 投诉 → 部件 → 同 MMY 召回（候选，带分数）→ 纠正措施**

1. 投诉 `11324947`（HONDA ACCORD 2018）→ 部件 `BACK OVER PREVENTION` → 召回 `18V629000`，方法 `mmy_comp_exact`，分数 **0.90**，抽检 **accepted**。措施：经销商免费重刷中控显示音频单元软件（备份摄像头显示故障召回）。同一投诉还候选到 `20V771000`（BCM 软件，分数 0.90 但本条未抽检，BCM 召回覆盖行也含倒车防撞，仍可能过宽）。
2. 投诉 `11499094`（HONDA CR-V 2018）→ 部件 `SEAT BELTS` → 召回 `23V158000`，方法 `mmy_comp_head`，分数 **0.60**，抽检 **accepted**。措施：必要时免费更换前排安全带锁扣按钮或锁扣总成。

**Q2 调查 → 召回（硬键）**

三条调查都查到了，但 `campno` 全空：

- `PE22003` / `EA24002`：Inadvertent Automatic Emergency Braking
- `PE22011`：Rear Differential Seizure

**本切片硬连接结果为 0。** 这不是查询写错，是官方平面文件里这些调查没有填写召回号。

**Q3 部件 → 故障码 → 维修步骤 / 零件**

投诉 `11407338`（CR-V 2018）挂着 `FUEL SYSTEM`，叙述正则抽出 `P0172`、`P0300`–`P0304`（叙述未入库）。这些码都在 CodesList，且都在 MechanicDB 样本中，硬键可以走到步骤和零件。例如：

- `FUEL SYSTEM` → `P0172` → “Replace stuck-open fuel pressure regulator” → 零件 Fuel pressure regulator
- `FUEL SYSTEM` → `P0300` → “Test fuel pump output pressure and delivery volume” → 零件 Electric fuel pump assembly

要如实说两点：① 部件到故障码只是同一投诉上的共现，不是官方结构；② 步骤来自公开样本，不能当成对该车的原厂维修手册。同投诉还可候选到燃油泵召回 `21V215000`、`23V858000`，与「油泵测试」步骤主题相近，但抽检同类燃油边的结论是 **uncertain**，不能当成已证实。

切片里没有 MechanicDB 覆盖的码（例如部分厂标码）会在这一步断开，只剩码表定义。

**Q4 问诊 → 部件 → 本切片 NHTSA 投诉数**

- 问诊 `Q70024`（本田 / 本田CR-V）→ `ENGINE` → **767** 条 2018 本田 CR-V/雅阁投诉（该主类）。
- 问诊 `Q70083`（本田 / 雅阁）→ `ENGINE` 767、`ELECTRICAL SYSTEM` 462、`POWER TRAIN` 161、`SERVICE BRAKES` 297。

词表还打出过「空调」，但本切片投诉没有 `AIR CONDITIONER` 主类，连接不上，计数为 0。问诊没有年款，这些数字是 2018 切片的部件池，不是同一辆车。

**Q5 投诉 → 调查（候选），并看是否已有召回硬键**

投诉 `11407338` 还有部件 `FORWARD COLLISION AVOIDANCE`，候选到 `EA24002` 与 `PE22003`（误触发自动紧急制动），`hasCampaign = false`。与 Q2 一致：调查侧能连上投诉，但再往召回走不通。

## 人工抽检 10 条候选边（投诉 → 召回）

只根据投诉的部件字段和官方召回缺陷摘要判断，**没有读投诉叙述**。`accepted` 表示字段上看起来像同一类部件问题，**不是** NHTSA 已确认该投诉就是这次召回。

| 投诉 ODINO | 车型 | 召回 | 主类 | 分数/方法 | 判断 |
|---|---|---|---|---|---|
| 11437883 | CR-V | 18V663000 | STEERING | 0.60 / head | **rejected**。召回是极小范围转向齿轮箱磁铁（潜在影响约 54 辆），不能用转向主类去接该年款大量转向投诉。 |
| 11324947 | ACCORD | 18V629000 | BACK OVER PREVENTION | 0.90 / exact | **accepted**。倒车防撞/后视 vs 备份摄像头显示，功能同类。 |
| 11301365 | ACCORD | 18V629000 | VISIBILITY | 0.60 / head | **uncertain**。视野主类还包括玻璃、雨刷等。 |
| 11519200 | ACCORD | 20V314000 | FUEL SYSTEM | 0.90 / exact | **uncertain**。方向是燃油系统，召回是燃油泵，不能断定就是油泵。 |
| 11299409 | CR-V | 23V858000 | FUEL SYSTEM | 0.60 / head | **uncertain**。同上，燃油泵召回。 |
| 11499094 | CR-V | 23V158000 | SEAT BELTS | 0.60 / head | **accepted**。安全带 vs 安全带锁扣，部件同类。 |
| 11383158 | ACCORD | 26V332000 | AIR BAGS | 0.60 / head | **uncertain**。召回是座椅重量传感器，与气囊有关但不是同一零件。 |
| 11339211 | ACCORD | 20V771000 | ELECTRICAL SYSTEM | 0.60 / head | **rejected**。BCM 软件通信召回 vs 电气主类过宽（该主类投诉号四百以上）。 |
| 11338688 | ACCORD | 20V771000 | EXTERIOR LIGHTING | 0.60 / head | **uncertain**。可能波及灯光，无法确认。 |
| 11309921 | ACCORD | 20V771000 | VISIBILITY | 0.60 / head | **uncertain**。可能波及显示，主类仍过宽。 |

合计：**accepted 2、rejected 2、uncertain 6**。

粗略准确率：把「看起来对」算作 2/10 = **20%**。只统计能下结论的 4 条，则 2/4。**不能把主类规则当成可自动展示的高置信追溯。** 演示默认应只出示硬键和抽检为 accepted 的候选。
